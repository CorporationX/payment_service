# Payment Service

Dummy service to accept payment requests from other services

Сервис автоматически загружает курсы валют при запуске, периодически их обновляет и далее хранит в кеше Redis.
- Настройки обновления, количество попыток соединения с внешним api и период обновления находятся в application.yaml
- Для корректной работы необходимо в application.yaml в параметр currency.rate.accessKey вставить ключ доступа,
например accessKey: 9cb123123123123be1c419 (этот ключ просто пример), рабочий ключ доступа необходимо
получить на сайте https://exchangeratesapi.io/ нажав на кнопку GET API KEY
- Для конвертации валюты необходимо отправить GET запрос на эндпоинт ("/currency"), указав в параметрах запроса 
переменные from (из какой валюты), to (в какую валюту) и amount (сколько конвертировать), 
например GET http://localhost:9080/currency?from=USD&to=RUB&amount=200
в ответ придет дробное число с количеством, с учетом комиссии.
- Комиссия (коэффициент пересчета) указывается в параметре conversionRateFactor и нужна для того, чтобы 
обеспечить конвертацию курса с учетом потери на разницах банковских курсов валют относительно биржи.
